# Cleanleaf

A lightweight, local-first document scanner for Android.

Scan documents, books, ID cards and whiteboards with the camera, or import images and PDFs. Cleanleaf detects the page edges, fixes the perspective, and cleans up the image so you get a crisp, readable scan. You can then reorder, sign, OCR and organize your pages, and export them to PDF, searchable PDF, JPEG or PNG. Everything runs on the device, so your scans stay private and work offline.
